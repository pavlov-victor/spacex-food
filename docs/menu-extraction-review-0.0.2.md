## Решение

По одному присланному результату оснований обязательно менять модель нет: полнота и цены сербского меню распознаны хорошо. Сначала исправить обработку валюты (явная настройка ресторана либо null), проверку диакритики и учёт каждого входного фото. Python-валидатор проверяет структуру и типы, но не сравнивает факты с пикселями: `status: ok` не означает подтверждённую точность OCR.

Сравнение с более сильной моделью имеет смысл только на одинаковом наборе фото по пропускам, ценам, написанию и времени выполнения. Новая модель в рамках этой проверки не запускалась; DSL 0.0.2 не изменён.
